# Cookie:Ro landing page prototype

Open `index.html` locally to preview. After three seconds, the Cookie:Ro cookie appears. Tap it to pull the scattered travel photos into the book; the LA Crumbook cover then arrives by itself with a warm glow and steam effect. Tap the right side of the cover to open it, then use the left and right halves to browse the four spreads from the supplied design. Press the right side on the final spread to close the book and reveal the “bake my crumbook” button on its “your trip, baked” back cover. The button scrolls to the Cookie:Ro flow guide below.

For GitHub Pages, upload `index.html`, `README.md`, and the complete `assets` folder to the repository root. Keep the folder name `assets` so image links continue to work. This is a static site and needs no build command.
